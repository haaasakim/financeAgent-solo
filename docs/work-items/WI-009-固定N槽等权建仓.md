# WI-009 回测固定 N 槽等权建仓

> 修复 WI-006 资金分配口径：候选不足 Top N 时，旧实现会把累计现金集中买入单只标的（实测出现单票满仓），
> 使「等权 Top N」退化为「单票满仓 + 择时」，策略对比失去可比性。本工作项冻结新的建仓口径。

## 1. 目标与范围

**目标**：回测建仓改为「固定 N 槽等权」——每只缺失目标按信号日组合净值的 `1/topN` 买入；候选不足 Top N 时剩余资金保持现金；已有持仓不动。消除单票满仓，保证不同策略/过滤条件的对比在同一仓位口径下进行。

**范围内**：

- `BacktestEngine` 买入预算口径与 `Order` 增加预算字段；`engine_version` 1 → 2。
- 单元测试：单候选只买 1/topN、后续目标不吞累计现金、原撮合/费用/涨跌停/停牌测试不回归。
- 真实数据回归验证与集中度检查。

**范围外**：

- 不做持仓再平衡/补仓/减仓：目标内已持有的仓位不调整，权重随行情漂移（一期保持「不追涨杀跌式微调」）。
- 不改变卖出规则、调仓频率、评分排序、费用、涨跌停、停牌、整手与延后规则。
- 不回填或重算历史任务：旧任务保留 `engine_version=1` 与其结果，新增任务用新口径。

## 2. 契约

**资金分配（替代 WI-006 §2.2 旧口径）**：

- 信号日 T 收盘计算组合总值 `NAV(T) = 现金 + 持仓按 T 日收盘价盯市`（停牌沿用最近收盘，与日度盯市一致）。
- 本信号新建买单的预算 = `floor(NAV(T) / topN, 2 位小数)`；同一批目标每只相同。
- 买单成交可买金额 = `min(预算, 成交日现金)`；股数 = `floor(可买金额 / 成交价(含滑点) / 100) × 100`；不足 100 股不成交（EXPIRED，沿用原因「现金不足百股」）。
- 候选不足 topN 时只买存在的目标，其余资金保持现金；候选为 0 时清仓持币（与旧口径一致）。
- 延后订单保留原信号日预算，不按成交日净值重算（避免使用成交日信息）。
- 已有持仓在目标内不买不卖；不在目标内卖出（旧口径不变）。

**无未来函数**：预算只使用 T 日收盘及之前数据；成交仍为 T+1 开盘。

**API**：无接口变更；`backtest_task.engine_version` 新任务写 `2`。

| 项 | 值 |
|---|---|

## 4. 实现要点

- `Order`：增加 `budget` 字段（卖出为 null；买单由 `rebalance` 传入 `NAV/ topN`）。
- `BacktestEngine.run`：信号日调仓前用 `marketValue(portfolio, priceBook, day)` 计算 `NAV(T)`，`slotBudget = NAV / topN` 传入 `rebalance`。
- `BacktestEngine.rebalance`：新建买单携带 `slotBudget`。
- `BacktestEngine.executeBuy`：删除「现金 ÷ 当日待买订单数」的均分逻辑，改为 `min(order.budget(), cash)`；现金不足保护保留。
- `BacktestService.ENGINE_VERSION = "2"`。

## 5. 异常、幂等与回滚

- 异常与失败处理：同 WI-006（任务级 FAILED，原因落库）。
- 幂等性保证：同一任务重复执行结果一致；参数落库可复现。
- 迁移与回滚：无数据库结构变更。回滚只需恢复旧资金分配逻辑；历史任务用 `engine_version` 区分，无需重算。

## 6. 验证

**验收标准**：单候选/少候选时不再出现「单票满仓」；每只买入金额 ≤ 信号日净值 / topN（现金不足除外）；原有撮合、费用、涨跌停、停牌、整手测试不回归；结果可复现。

- 结论：集中度修复后收益几乎不变，说明 A 策略的问题在选股与换手，不在仓位；修复的价值是消除单票满仓暴露、使策略对比可比。

- 反转确认、去低波、限深跌三类改动在公平口径下依然显著弱于基线 → 基线的超额来自「深度超跌 + 低波动 + 短周期均值回归」，入场过滤器会破坏该逻辑。

**边界覆盖**：topN=1（预算=NAV，行为同旧口径）/ 候选 1 只时现金闲置 / 累计现金不被单只目标吞掉 / 延后订单预算不重算 / 现金不足百股。

## 7. 未验证项与剩余风险

- 权重漂移：存量持仓不调回目标权重，牛市中长期权重高于 1/topN，属一期取舍。
- 换手结构与旧口径不同，历史策略收益不可与旧任务直接比较（这正是本项目的）。
- 每日频率下每次信号重算 NAV，若当日大量停牌持仓按最近收盘计，预算略偏离真实可交易价值。
- 集中度修复未改善严格过滤策略的收益：其低收益由选股与择时造成，后续改进方向应转向出场风控（止损/时间止损，需另立工作项）。
