## 1. 目标与范围

**目标**：落地市场模块——快照数据补全估值与成交字段，提供全市场标的列表（筛选 / 排序 / 分页）与个股日K详情页，同时搭好前端基建（layout、HTMX、ECharts、静态资源本地化）。

**范围内**：

- 新增 `market_snapshot` 表，落全市场最新快照：最新价、涨跌幅、成交量、成交额、换手率、PE、PB、总市值、流通市值
- 新浪快照 Provider 扩展价格类字段（`trade` / `changepercent` / `volume` / `amount`）
- 指数行情同步：4 个指数（上证指数 / 深证成指 / 创业板指 / 沪深300）入 `instrument` + `daily_bar`
- 市场页：指数概览条 + 全市场标的表格（关键词 / 板块 / 类型筛选，8 列排序，分页）
- 个股详情页：日K（蜡烛 + MA5/10/20/60 + 成交量）与区间切换
- 前端基建：`templates/layout` 骨架、`static/js` 本地库（HTMX / Alpine / ECharts）、`app.js`、`app.css` 扩展
- 同步产出条数校验、幂等与失败整批拒绝
- 单元测试与真实链路验证

**范围外**：

- 异步任务框架与页面触发同步（仍走命令行）
- `daily_bar.amount / turnover_rate` 的历史回填。原因：新浪快照不带交易日，无法可靠判定快照归属日；错误回填会污染日K。列为后续工作
- 选股与回测页面（M3 / M4）
- 分钟级行情、盘口、实时刷新（一期不做）

## 2. 契约

### 2.1 数据库变更（迁移 V2）

**market_snapshot**：每个标的保留最新一条快照。

| 列 | 类型 | 约束 | 说明 |
|---|---|---|---|
| instrument_id | TEXT | PK | `600000.SH` |
| last_price | REAL | | 最新价，元；停牌 / 无成交为 NULL |
| pct_chg | REAL | | 涨跌幅，小数 |
| volume | INTEGER | | 成交量，股 |
| amount | REAL | | 成交额，元 |
| turnover_rate | REAL | | 换手率，小数 |
| pe_ttm | REAL | | 市盈率 TTM，倍；亏损为 NULL |
| pb | REAL | | 市净率，倍 |
| total_mv / circ_mv | REAL | | 总市值 / 流通市值，元 |
| source | TEXT | NOT NULL | 如 `SINA_MARKET_CENTER` |
| fetched_at | TEXT | NOT NULL | 抓取时刻，即该行数据的 available_at |
| data_status | TEXT | NOT NULL DEFAULT `ACCEPTED` | |
| created_at / updated_at | TEXT | NOT NULL | |

### 2.2 Provider 接口

`SnapshotProvider` 方法签名不变，`InstrumentSnapshot` 增加字段：

```java
public record InstrumentSnapshot(
        String symbol, String code, String name,
        Double lastPrice, Double pctChg, Long volume, Double amount,
        Double peTtm, Double pb, Double totalMv, Double circMv, Double turnoverRate)
```

新浪字段映射（单位换算全部在 Provider 内完成）：

| 新浪字段 | 本站字段 | 换算 |
|---|---|---|
| `trade` | lastPrice | 元；≤ 0 视为无成交，置 NULL |
| `changepercent` | pctChg | 百分数数值 → 小数（÷100） |
| `volume` | volume | 股（原样） |
| `amount` | amount | 元（原样） |
| `per` | peTtm | ≤ 0 置 NULL |
| `mktcap` / `nmc` | totalMv / circMv | 万元 → 元（×10000） |
| `turnoverratio` | turnoverRate | 百分数数值 → 小数（÷100） |

### 2.3 同步任务

| 任务名 | CLI | 语义 |
|---|---|---|
| `SYNC_MARKET_SNAPSHOT` | `--sync.snapshot` | 拉全市场股票 + ETF 快照，整批 upsert；失败不写部分数据 |
| `SYNC_INDEXES` | `--sync.indexes` | 按配置 upsert 指数标的并拉 10 年日K（复用腾讯 Provider） |

指数清单入配置，不入库为硬编码：

```yaml
finance:
  market:
    indexes:
      - id: "000001.SH"
        name: "上证指数"
      - id: "399001.SZ"
        name: "深证成指"
      - id: "399006.SZ"
        name: "创业板指"
      - id: "000300.SH"
        name: "沪深300"
```

### 2.4 页面路由

| 路由 | 返回 | 说明 |
|---|---|---|
| `GET /` | 页面 | 数据总览（沿用） |
| `GET /market` | 页面 | 市场页：指数概览 + 标的表格 |
| `GET /market/stock/{instrumentId}` | 页面 | 个股详情；`range=3m/6m/1y/3y/all`，默认 `6m` |
| `GET /fragments/market/table` | 片段 | HTMX 表格局部刷新；参数 `keyword/board/type/sort/dir/page/size` |

排序字段白名单（controller 绑定枚举，非法值 400；SQL 中列名来自枚举，不来自用户字符串）：
`code` / `name` / `lastPrice` / `pctChg` / `amount` / `turnoverRate` / `peTtm` / `totalMv`。

分页统一：`page` 从 1 开始，`size` 默认 20、上限 200。

## 3. 数据语义

| 项 | 值 |
|---|---|
| 市场 / 币种 / 时区 | A 股 / CNY / Asia/Shanghai |
| 复权方式 | 日K 前复权（QFQ），快照为不复权最新价 |
| 数据来源 | 新浪 `Market_Center`（快照）、腾讯 `fqkline`（日K / 指数） |
| 可用时点 available_at | 快照 = `fetched_at`（抓取时刻）；指数日K = 当日收盘后 |
| 单位与精度 | 价格元、成交量股、百分比小数、市值元 |

## 4. 实现要点

1. **快照整批写入**：先完成全量拉取与映射，再在一个事务内分批 upsert；任何一批失败整体回滚。
2. **落库条数校验**：`SELECT COUNT(*) WHERE fetched_at = :runAt` 必须等于映射条数，且拉取列表非空。
3. **幂等**：`ON CONFLICT (instrument_id) DO UPDATE`；重复执行行数不变，`fetched_at` 更新为最近一次。
4. **详情页无假数据**：`market_snapshot` 无记录时页面展示 `--`，不回填 0。
5. **K线均线在浏览器端计算**（app.js），服务端只下发前复权 OHLCV，避免 M2 提前引入指标层。
6. **HTMX**：表格筛选 / 排序 / 分页均局部刷新；片段路由在 `/fragments/**`；错误返回错误片段而非整页。

## 5. 异常、幂等与回滚

- **异常**：Provider 解析失败抛 `DataSyncException`（可重试）；条数校验失败抛 `DataIntegrityException`（不可重试）。同步失败记录 `sync_log` 并整批拒绝。
- **幂等**：快照以 `instrument_id` 为 PK upsert；指数与日K走既有 upsert。
- **回滚**：新增表与代码，无历史数据变更。回滚 = 回退代码提交；`market_snapshot` 为空表，亦可 `DROP TABLE`。数据库文件不入版本控制。

1. `./mvnw test` 全绿，`./mvnw clean package` 构建通过

3. 市场页：筛选 / 排序 / 分页可用，空数据与错误状态可展示
4. 个股详情页：K线 + 均线 + 成交量渲染正确，区间切换可用

**浏览器验证（2026-09-13，Chrome headless 截图）**：

- `/market` 1440 / 768：指数概览 + 7,220 只标的 + 8 列排序 + 分页（361 页）正常，涨红跌绿
- `/market/stock/000001.SZ?range=1y|3m` 1440 / 768：蜡烛 + MA5/10/20/60 + 成交量 + dataZoom 渲染正常

## 7. 未验证项与剩余风险

- **全量 7,220 标的的 10 年日K仍未初始化**（M1 只跑了 50 只样本）。市场列表依赖快照已可用，但多数标的详情页目前是空状态，需执行 `--sync.init=0` 后补齐
- `daily_bar.amount / turnover_rate` 仍为 NULL（腾讯不提供）。快照表已有最新交易日数据，但**未回填日K**：新浪快照不带交易日，错误归属会污染历史，回填方案需结合交易日历另行设计
- `market_snapshot` 仅保留最新一条，不能按历史日期回溯 PE/PB/市值；选股与回测若使用估值因子，需要新增时序表
- 新浪 456 限流下快速重复触发仍可能失败；页面同步入口与冷却提示留待异步任务框架
- 页面中的空状态与错误片段已验证渲染，但 HTMX 点击交互未做自动化测试，由真实浏览器渲染确认
- 实际标的数 7,220 与设计稿 6,612 的差异来自北交所与 ETF 口径，属预期
