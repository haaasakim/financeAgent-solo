## 1. 目标与范围

**目标**：落地选股模块——条件构建器（因子 + 运算符 + 阈值，分「全部满足 / 任一满足 / 排除」三组）、
预设策略模板、结果表格、保存/加载/删除策略；导航开放「选股」。

**范围内**：

- V4 迁移：`strategy` 表（条件树 JSON 持久化）
- `screener/dsl`：规则树模型、运算符白名单、JSON 解析与校验
- `screener/factor`：因子注册表（可用因子 + 财务因子占位）
- `ScreenerQueryMapper`：DSL 经白名单映射为参数化 SQL 求值
- `ScreenerService`：求值、策略增删查、预设模板
- 页面：因子目录树、条件卡片（Alpine 管 UI 状态）、结果表格（HTMX）、四态处理
- 导航「选股」开放；「拿去回测」置灰标注 M5
- 测试：DSL 校验、真实 SQLite 求值、策略保存/加载、页面渲染

**范围外**：

- 财务因子（股息率 / ROE / 资产负债率 / 营收同比 / 净利同比）依赖财报数据源，因子树中灰显占位
- 回测（M5）；「拿去回测」仅置灰提示
- 多策略组合、参数寻优、结果导出

## 2. 契约

### 2.1 表结构（迁移 V4）

**strategy** 策略表。

| 列 | 类型 | 约束 | 说明 |
|---|---|---|---|
| id | INTEGER | PK AUTOINCREMENT | |
| name | TEXT | NOT NULL UNIQUE | 策略名，重名保存视为覆盖更新 |
| description | TEXT | | 说明 |
| dsl | TEXT | NOT NULL | 条件树 JSON |
| created_at / updated_at | TEXT | NOT NULL | |

### 2.2 条件树 DSL

```json
{
  "all": [ {"factor": "peTtm", "op": "lte", "value": 30} ],
  "any": [],
  "not": [ {"factor": "listedDays", "op": "lt", "value": 60} ]
}
```

- `factor`：因子注册表 key（白名单，未知或不可用因子拒绝）
- `op`：`gt` / `gte` / `lt` / `lte` / `eq`（白名单）
- `value`：数字；布尔因子取 `1`（是）/ `0`（否）
- 组语义：
  - `all`：全部条件同时满足（AND）
  - `any`：至少满足一个（OR）
  - `not`：排除同时满足该组全部条件的标的（`AND NOT (c1 AND c2 ...)`）
  - 空组不参与
- 校验：单组条件 ≤ 20、总条件 ≤ 50；数值必须有限且 `|value| ≤ 1,000,000`

### 2.3 因子注册表（M4 可用集合）

| 组 | key | 展示名 | 类型 | 口径 |
|---|---|---|---|---|
| 基础 | `excludeSt` | 非 ST | 布尔 | 名称不含 ST |
| 基础 | `tradable` | 非停牌（最近交易日在市） | 布尔 | 最新日K日期 = 全市场最新日K日期 |
| 基础 | `listedDays` | 上市天数 | 数值（天） | `今天 - listed_at`，近似值 |
| 估值 | `peTtm` | PE-TTM | 数值（倍） | `market_snapshot.pe_ttm` |
| 估值 | `pb` | PB | 数值（倍） | `market_snapshot.pb` |
| 趋势 | `return20` / `return60` | 20 / 60 日收益 | 数值（%） | `factor_daily.return_* × 100` |
| 趋势 | `aboveMa60` | 站上 MA60 | 布尔 | 最新收盘 > `factor_daily.ma60` |
| 趋势 | `ma20GtMa60` | MA20 > MA60 | 布尔 | `factor_daily.ma20 > ma60` |
| 风险 | `volatility20` | 20 日波动率 | 数值（%） | `factor_daily.volatility_20 × 100` |
| 风险 | `pctFrom52wHigh` | 距 52 周高点 | 数值（%） | `factor_daily.pct_from_52w_high × 100`（≤ 0） |

财务占位（不可选，灰显）：`dividendYield` 股息率、`roeTtm` ROE-TTM、`debtRatio` 资产负债率、
`revenueYoy` 营收同比、`profitYoy` 净利同比。

**技术因子取每只标的最新一行**（`factor_daily` 按 `(instrument_id, trade_date)` 取 MAX），
因此选股结果是「截至最新交易日的截面」。

### 2.4 路由

| 路由 | 方法 | 返回 | 说明 |
|---|---|---|---|
| `/screener` | GET | 页面 | 参数 `template=KEY` / `strategyId=N` 预填条件 |
| `/fragments/screener/results` | POST | 片段 | 参数 `dsl`(JSON)、`page`；结果表 + 分页 |
| `/fragments/screener/strategies` | POST | 片段 | 参数 `name`、`description`、`dsl`；保存并返回策略列表 |
| `/fragments/screener/strategies/{id}/delete` | POST | 片段 | 删除并返回策略列表 |

结果分页：`page` 从 1 开始，`size` 固定 50，匹配总数上限 5,000（超出仅展示计数）。

> 排序与展示列已由 `docs/work-items/WI-005-选股评分与排序.md` 扩展：
> 结果按评分（命中集内相对百分位）降序，结果表增加「评分」列。

## 3. 数据语义

| 项 | 价值 |
|---|---|
| 市场 / 币种 / 时区 | A 股 / CNY / Asia/Shanghai |
| 复权方式 | 前复权（技术因子） |
| 数据来源 | 本地 `factor_daily` + `instrument` + `market_snapshot`，无外部请求 |
| 可用时点 | 技术因子 = 对应交易日收盘后；估值 = 快照抓取时刻 |
| 单位与精度 | 百分比因子页面按 % 输入，DSL 存展示值；SQL 中乘 100 后比较 |

## 4. 实现要点

1. **用户输入永不进入 SQL 结构**：因子 key → 白名单表达式、op → 白名单符号，
   全部由服务端枚举解析后再交给 Mapper；值走 `#{}` 参数。
2. **HTMX 局部刷新**：执行选股、分页、保存/删除策略均返回片段；条件卡片由 Alpine 管理纯前端状态。
3. **策略重名覆盖**：`ON CONFLICT(name) DO UPDATE`，保存幂等。
4. **校验失败**：抛 `BusinessException`，返回错误片段（不展示堆栈）。
5. **「拿去回测」置灰**：M5 未实现，不保留可点击假交互。

## 5. 异常、幂等与回滚

- **异常**：DSL 非法、因子未知/不可用、数值越界 → `BusinessException`（用户可见）；
  SQL 执行失败走 `WebExceptionHandler`。
- **幂等**：策略保存按 name upsert；查询只读。
- **回滚**：新增表与代码；`strategy` 可清空重建，无历史数据变更。

## 7. 未验证项与剩余风险

- 财务因子不可用，预设模板已适配现有数据；财报数据源落地后需扩展注册表与模板
- 结果为最新截面，不支持历史时点选股（回测将另行处理时点求值）
- 技术因子仅覆盖已同步日K的标的；未同步标的不会命中技术条件
- 「排除停牌」以「最新日K日期 = 全市场最新日期」近似，长期停牌股会被排除
- 条件求值未加复合索引；7 千级标的下实测毫秒级，标的量级增长后再评估
- 条件卡片为纯前端状态，刷新页面未保存的条件会丢失（可先保存为策略）
