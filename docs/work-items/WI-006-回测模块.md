## 1. 目标与范围

**目标**：用已保存的选股策略做历史回测，输出净值、回撤、绩效指标与交易流水；结果可复现、无未来函数、成交受涨跌停与停牌约束。

**范围内**：

- 单策略、单标的池（策略当期命中集）、目标持仓 Top N、等权
- 参数：区间、调仓频率（周 / 月 / 季）、持仓数、初始资金、佣金率与最低佣金、印花税（卖出）、滑点、基准
- 信号时点 T 日收盘，成交时点 T+1 开盘；T 日只能使用 `available_at <= T` 的数据
- 费用与成交约束：佣金、印花税、滑点、100 股整手、现金约束、停牌跳过/延后、一字涨跌停不可成交（订单状态如实落库）
- 日度净值、回撤、基准对比与绩效指标；结果与订单落库
- 后台任务执行 + 页面轮询进度；回测历史列表
- 选股页「拿去回测」入口（已保存策略可直接跳转）

**范围外**（一期明确不做）：

- 多策略组合、参数寻优、分钟级回测、做空 / 融资融券、分红再投资、退市整理期
- 部分成交（整手整笔撮合，不能成交则延后或作废）
- 历史估值因子（PE/PB 快照无历史序列）——WI-007 已补 `valuation_daily` 历史估值数据源，见 4.3
- 精确历史 ST 状态（用当前名称近似，见 4.4）

### 2.1 信号与调仓

- 调仓信号日：每个周 / 月 / 季度的**最后一个交易日**（交易日取自 `trading_calendar`，由基准指数日K回填）。
- 信号求值：以信号日 T 为截面，按策略 DSL 求值并评分（口径与 WI-004 / WI-005 完全一致），取评分前 N 名为目标持仓；评分同为 1 位小数时按 `instrument_id` 升序。
- 目标持仓等权；已有持仓在目标内则不动，不在目标内则卖出，缺失目标买入。
- 区间内最后一个信号日的 T+1（成交日）若超出结束日，则该期不调仓，仅盯市。

### 2.2 成交与费用

- 成交价：T+1 开盘价（前复权）加滑点——买入 `open × (1 + slippage)`，卖出 `open × (1 - slippage)`。
- 佣金：`max(amount × commission_rate, 5 元)`，买卖双边。
- 印花税：卖出 `amount × stamp_tax_rate`，买入不收。
- 100 股整手：买入股数 = `floor(预算 / 成交价 / 100) × 100`；不足 100 股不成交（现金保留）。
- 资金分配：先卖后买，可用现金按剩余目标数均分，逐个向下取整到百股。
- 买入未成交时该笔预算保留，不转投其他标的。
- 不能成交判定与处理（每个交易开盘时重试，回测结束仍未成交 → EXPIRED）：
  - 停牌（当日无日K）→ 延后至下一可交易日；
  - 一字涨停（买入）→ 当日 `open == high == low == close` 且开盘价触及涨停价 → 延后；
  - 一字跌停（卖出）→ 同理 → 延后。
- 涨跌停判定：以上一日 `pre_close` 按板块与 ST 状态计算涨停价（见 4.4），容差 ±0.005 元；不单独使用 `pct_chg`。

### 2.3 绩效口径（全部小数，展示层转百分号）

- 累计收益 = `nav_last / initial_capital - 1`
- 年化收益 = `(nav_last / initial_capital) ^ (365 / 区间自然日数) - 1`
- 最大回撤 = `min(nav / 历史峰值 - 1)`，负数
- 夏普 = `mean(日收益) / std(日收益, n-1) × sqrt(252)`，无风险利率取 0；样本不足或标准差为 0 时为 NULL
- 胜率 = 已平仓卖出中「净卖出金额（扣费）> 该笔持仓平均成本（含买入费）」的笔数占比
- 年化换手 = `(Σ买入金额 + Σ卖出金额) / 2 / 平均净值 / 年数`
- 基准净值 = `基准收盘 / 首日基准收盘 × initial_capital`；超额 = 策略累计收益 − 基准累计收益

### 2.4 任务与进度

- 任务状态机 `PENDING → RUNNING → SUCCESS | FAILED`；失败时 `message` 记录原因。
- 异步执行用专用线程池（核心 2、最大 4、队列 100）；页面每 2s 轮询，进度按交易日计数，每 20 个交易日写库一次。
- 每次回测创建新任务记录并输出独立结果，重复执行不覆盖历史（幂等语义：同一任务重复执行结果一致，不产生重复数据）。

## 3. 数据语义

| 项 | 值 |
|---|---|
| 市场 / 币种 / 时区 | A 股（沪深主板 / 创业板 / 科创板 / 北交所）/ CNY / Asia/Shanghai |
| 复权方式 | 前复权（qfq），与 `daily_bar` / `factor_daily` 一致；持有期不做分红现金处理 |
| 数据来源 | 本地 `daily_bar`、`factor_daily`、`instrument`、`trading_calendar`（均由同步任务落库） |
| 可用时点 available_at | 日K与因子以收盘后可用的假设使用：信号日 T 使用 T 日收盘数据，成交在 T+1 开盘 |
| 单位与精度 | 价格 / 金额单位元，股数为股；账户资金、费用、持仓市值运算全程 `BigDecimal`，日度序列落库转 `double` 仅用于展示与图表 |

**数据快照标识**：`params_json` 记录 `data_through`（运行开始时的最大日K日期）、基准、引擎版本与全部参数；`strategy_hash` 记录策略定义。同参数 + 同数据 + 同策略必得同结果。

**回测不使用的数据**：`market_snapshot`（仅最新截面，无历史序列，使用即构成未来函数）。

## 4. 实现要点

### 4.1 包结构

```
backtest/
  engine/   BacktestEngine, BacktestParams, Portfolio, Position, Order,
            RebalanceFrequency, PriceBook, BoardLimit
  cost/     TradingCost
  metric/   PerformanceMetrics, BacktestMetrics
  BacktestService.java（异步执行、持久化、查询）
```

### 4.2 截面求值（时点选股）

- `ScreenerQueryMapper` 增加按交易日截面的查询：`countCandidatesAt` / `findAllCandidatesAt` / `findFactorValuesAt`，以 `factor_daily.trade_date = #{asOf}` 连接；`ScreenerService` 增加 `evaluateAt(dsl, asOf, limit)`，评分逻辑与最新截面共用同一实现。
- `FactorRegistry` 的因子增加「历史截面表达式」：基础与趋势/风险类因子可由 `factor_daily` 时点行复算；表达式引用 `f.trade_date` 作为截面日，不拼用户输入。
- 上市不足 5 个交易日的标的排除：以该标的截至 T 的日K条数 ≥ 5 为准（不足剔除）。

### 4.3 历史数据边界（重要限制）

- **估值因子（PE-TTM / PB）由 WI-007 提供逐日历史序列**（`valuation_daily`，东财数据中心，约 2017 年起），
  历史截面按 `v.trade_date = f.trade_date` 取当日值，不再使用最新快照；开始日期早于估值覆盖起点时返回用户可见提示。
  财务占位因子（ROE / 营收同比等）仍无数据源，含这些条件的策略禁止回测。
- 只支持 `factor_daily` 中可复算的技术因子、`valuation_daily` 的估值因子与基础条件
  （`excludeSt` / `tradable` / `listedDays` / `return20` / `return60` / `aboveMa60` / `ma20GtMa60` / `volatility20` / `pctFrom52wHigh` / `peTtm` / `pb`）。

### 4.4 涨跌停与 ST

- 幅度按「板块 × 风险警示」取值：主板 ST ±5%、主板 ±10%、创业板 / 科创板 ±20%、北交所 ±30%、ETF ±10%。
- 历史 ST 状态无数据源，**用当前 `instrument.name` 含 `ST` 近似**，可能低估/高估历史涨跌停；记录在剩余风险。
- 一字板判定：`open == high == low == close` 且开盘价与按上述幅度算出的涨跌停价之差 ≤ 0.005 元。
- 不实现部分成交；停牌、涨跌停导致的未成交按整笔延后处理。

### 4.5 交易日历

- 回测运行前用基准指数日K幂等回填 `trading_calendar`（`is_open = 1`，只补不删），再按区间读取交易日；不按自然周推导。

## 5. 异常、幂等与回滚

- 失败处理：单个订单不成交不算失败；引擎异常时任务置 FAILED 并记录消息，不写入半截日度序列（同一任务的结果写入在成功结束后批量落库，或按任务 id 覆盖写）。
- 幂等性：任务结果全部按 `task_id` 归属，重复执行同一参数生成新任务、结果一致；迁移均为 `CREATE TABLE IF NOT EXISTS`，可重复执行。
- 迁移与回滚：V5 只新增表与索引，回滚只需停止使用新表和路由，不触碰既有数据；不修改任何已有表结构。

## 6. 验证

**验收标准**：

- 固定数据快照下，连续执行两次结果逐位一致；修改未来数据不影响历史净值（无未来函数）。
- 涨停一字板不可买入、跌停一字板不可卖出、停牌跳过并延后；订单状态如实落库。
- 费用断言：佣金最低 5 元、卖出印花税、滑点方向正确、买入 100 股整手。
- 模板页面在 1440 / 768 宽度可用，四态（加载 / 有数据 / 空 / 错误）齐全。

**边界覆盖**：正常 / 无命中（空候选净值恒为初始资金）/ 停牌延后 / 一字涨停延后 / 现金不足 100 股 / 估值因子拒绝与覆盖校验 / 同参数复现

**实现修正**：

- 信号与成交严格分离：信号日 T 用 T 日因子截面评分，成交明细的 `filled_date` 均为 T+1；
  单测额外覆盖「T+1 因子更强也不影响 T 日选股」。
- 初始资金输入 `step=10000` 与 `min=1000` 组合使 1,000,000 不是合法步进值，浏览器会静默阻止
  表单提交；已改为 `step=1000`，并用真实浏览器全流程回归。
- 涨跌停幅度按「板块 × 风险警示」实现（注册制板块 ST 不降幅），`docs/DATA_CONTRACT.md` 第 6 节同步修正。

## 7. 未验证项与剩余风险

- 前复权价格在除权后重写历史：跨越除权日的回测存在轻微未来偏差（沿用一期复权契约）
- 历史 ST 用当前名称近似；退市、更名、重组等历史状态无法还原
- 佣金 / 印花税 / 滑点为参数假设，与真实券商费率可能不同
- 整手整笔撮合、无部分成交与排队假设；开盘集合竞价成交按开盘价线性滑点近似
- 基准仅支持已同步的 4 个指数（上证指数 / 深证成指 / 创业板指 / 沪深300）
- 本机数据仅覆盖已同步日K的标的（数据同步进度决定可回测样本）
