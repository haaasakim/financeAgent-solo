## 1. 目标与范围

**目标**：候选池 `instrument_type IN ('STOCK','ETF')` 固定包含 ETF，在 WI-014 区间评分下
ETF（尤其债券 ETF）会挤占股票策略的排序前列（如趋势回踩被「科创债 / 国开0-3」霸榜）。
提供「仅股票」基础因子让策略显式限定标的类型，并据此重新调整现有策略评分。

**范围内**：

- `FactorRegistry` 新增基础布尔因子 `stockOnly`（最新截面与历史截面表达式相同）
- 测试：页面 / 最新截面 / 历史截面（回看）三处口径一致
- 策略数据调整：`EV3-新高放量`、`候选-温和放量新高`、`候选-趋势回踩`
  （新增仅股票过滤 + 改用 WI-014 区间评分）；`候选-缩量超跌`、`候选-缩量超跌回稳`、
  `候选-深度乖离回归`、`超跌企稳` 经复核不变（单调方向与策略意图一致）
- `script/batch_backtest.py` 内策略定义与库内 DSL 保持逐字节一致（`--create-only` 不会回退）

**范围外**：

- 修改候选池默认范围（仍为 STOCK + ETF，需策略自行加条件）
- 新增「仅 ETF」「排除北交所」等类型因子
- 对调整后的策略跑回测（用户要求先只看选股结果）

## 2. 契约

### 2.1 因子定义

| key | 分组 | 标签 | 类型 | 表达式（最新 / 历史） |
|---|---|---|---|---|
| `stockOnly` | 基础 | 仅股票 | BOOLEAN | `CASE WHEN i.instrument_type = 'STOCK' THEN 1 ELSE 0 END` |

- 用法：条件 `{"factor":"stockOnly","op":"eq","value":1}`（是 = 仅股票，否 = 仅 ETF）。
- 历史截面同样可回测/回看（`i` 在 `baseFromAt` 中可用），无未来函数。

### 2.2 策略调整（只改评分与候选范围，不改交易口径）

| 策略 | 调整 |
|---|---|
| EV3-新高放量 | 新增仅股票；volumeRatio5 → band [1.2, 2.5]；bias20 → band [0, 10] |
| 候选-温和放量新高 | 新增仅股票；volumeRatio20 → band [1.2, 2.0] 权重 2；bias20 → lower 权重 1；return60 取消评分 |
| 候选-趋势回踩 | 新增仅股票；bias20 → band [-2, 4] 权重 2；downsideVol20 → lower 权重 1；return60 仅过滤 |

## 3. 实现要点

1. `FactorRegistry` 基础分组新增 `stockOnly`（布尔，两套表达式均可用）。
2. 策略调整经 `POST /fragments/screener/strategies`（服务端校验）写库；旧版本已备份
   `data/strategy-backup-2026-09-17.json`。
3. 批量脚本 `cond()` 支持区间字段，5 个策略定义与库内 DSL 一致性由脚本自查。

## 4. 异常、幂等与回滚

- **校验**：布尔因子只允许 `eq` 0/1（沿用现有校验）。
- **幂等**：因子求值为只读；策略保存同名覆盖；脚本重复执行不产生重复策略。
- **回滚**：策略用备份文件恢复；`stockOnly` 为纯代码新增，回退代码即可。
