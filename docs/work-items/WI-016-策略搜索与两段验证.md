## 1. 目标与范围

**目标**：遍历现有因子组合成策略，按「日频 / 持仓 5 / 费用默认」两段回测
（A：2018-01-02 ~ 2024-01-01；B：2024-01-02 ~ 2026-09-11），自我迭代，
删除两段都亏损的策略，寻找稳定盈利的策略。

**范围内**：策略 DSL 组合与参数（阈值、方向、权重、区间、止损、时间止损）；
候选创建 / 提交 / 轮询 / 报表 / 剪枝脚本；稳健性子区间抽检（SUB1 2018-2020、
SUB2 2021-2023、SUB3 2025-2026）。

**范围外**：手续费、频率、持仓数（用户固定）；退市股补数；实盘验证。

## 2. 固定条件与剪枝规则

## 3. 迭代过程（共 6 代、65 个候选、约 150 个日频任务）

| 代 | 候选数 | 主题 | 主要发现 |
|---|---|---|---|
| G1 | 35 | 低波 / 趋势 / 反转 / 量能 / 估值 / ETF 全家桶 | 换手 50+ 的策略几乎全灭；低换手低波在 A 段 +15~29% |
| G2 | 10 | 低换手 + 慢趋势门 | 出现首个双窗口盈利（低波趋势分 +5.0/+9.9） |
| G3 | 6 | 浅回撤过滤 + 软趋势分 | 重权趋势分 A +11.9 / B +18.1 |
| G4 | 6 | 价值倾斜 / 纯权重对照 | 价值倾斜毁 A 段；重权本身贡献有限 |
| G5 | 5 | 双赢微调 | 慢门版 A +22.4 / B +18.7（最佳双赢） |
| G6 | 3 | 稳定性终极测试（A/B/SUB2） | 防御家族最稳但 B 段仍 -1.3~-2.4% |

## 4. 关键发现

1. **换手是生死线**：A 段 +22.9% 的「浅回撤」换手约 10；换手 50+ 的「重权趋势分」
   虽双赢，但 A 段累计手续费 47.6 万 / 100 万本金，靠毛利硬扛。
2. **双窗口盈利候选（按 A/B 判定）**：

   | 策略 | A | B | 换手 A/B | 回撤 A/B |
   |---|---|---|---|---|
   | 实验-G5-低波重权慢门 | +22.4% | +18.7% | 59.8 / 72.3 | -29.4% / -23.8% |
   | 实验-G3-低波重权趋势分 | +11.9% | +18.1% | 58.3 / 72.1 | -32.4% / -22.7% |
   | 实验-G2-低波趋势分 | +5.0% | +9.9% | 68.4 / 80.7 | -32.4% / -22.3% |
   | 实验-G5-低波重权窄震 | +5.5% | +9.5% | 53.8 / 70.5 | -33.1% / -22.8% |
   | 实验-G5-低波重权重回撤 | +4.6% | +3.8% | 51.6 / 64.8 | -28.1% / -23.4% |

3. **稳定性抽检（关键）**：双赢家族在 SUB1（2018-2020）为 +52~58%，
   但 SUB2（2021-2023）为 **-23~-28%**，SUB3（2025-2026）≈ +1.5%——
   A 段盈利集中在 2018-2020，B 段盈利集中在 2024，**没有出现全子区间为正的策略**。
4. **最接近全稳的组合**：`实验-G6-极浅微趋势`（A +14.9 / SUB2 +0.6 / B -1.3）、
   `实验-G3-低波极浅回撤`（A +16.0 / SUB2 +0.9 / B -1.3）、
   `实验-G4-极浅趋势门`（同口径）——低换手（约 10）防御族，只在 B 段小亏。
5. **剪枝结果**：32 个双亏策略已通过删除接口清理（含全部高换手趋势 / 反转 / 量能族），
   保留 30 个至少一段盈利的策略；结果快照 `data/strategy-research-2026-09-17/`。

## 5. 结论

- 按用户的判定标准（A/B 两段），**最佳答案是 `实验-G5-低波重权慢门`**：
  两段均盈利、回撤约 -29% / -24%；但它依赖 2018-2020 与 2024 两个有利阶段，
  2021-2023 会亏 -23%，且换手高、成本敏感。
- 若以「稳定」为第一优先，`实验-G6-极浅微趋势`（或 G3-低波极浅回撤）更诚实：
  三个子区间 2/3 为正，唯 B 段约 -1.3%，换手低、成本不敏感。
- 在本系统的约束（日频、持仓 5、费用固定、无退市股数据、无市场状态输入）下，
  **不存在已被证明的稳定盈利策略**；上述结果是样本内筛选，不构成投资建议。

## 6. 未验证项与剩余风险

- 样本内选择偏差：65 个候选里挑出双赢，前向表现大概率低于回测
- 幸存者偏差：库内只有当前存续标的，A 段收益被系统性高估
- 换手成本敏感：双赢候选对费率/滑点假设敏感，实际成交可能更差
- 未做参数区间扫描（阈值 ±10% 的敏感性）与滚动前向验证
- 数据范围：估值因子自 2017 年起；早年 ETF 数量少
