## 1. 目标与范围

**目标**：补充两类因子，改变当前因子体系「全部由收盘价派生」的单一口径：

- **P0（注册表，无新列）8 个**：已有 `factor_daily` 列但未注册的 RSI / MACD 柱 /
  均线乖离 / MA20 与均线排列；
- **P1（新列 + 回填）9 个**：量能（量比、量能变化）与日内/位置（ATR、振幅、下行波动、
  距 52 周低点、60/120 日新高）。

**范围内**：

- `V7__factor_daily_v2.sql`：`factor_daily` 增加 9 列（可空，无默认值）
- `FactorCalculator` 与新指标类；`--factor.init` 全量回填、`--factor.update` 增量重算
- `FactorRegistry` 注册 17 个因子（含新增「量能」分组）
- 单测：新指标固定快照对拍、边界（回看不足、除零、停牌缺口）、计算器集成
- 文档：本文件、WI-003 注记、DATA_CONTRACT 说明

**范围外**：

- 换手率 / 成交额因子：`daily_bar.turnover_rate` 与 `daily_bar.amount` 当前全为 NULL
  （腾讯日K不提供），需先补数据源（另立任务）；不写估算值进正式表
- 财务因子（股息率 / ROE 等）与资金流因子（需新 Provider）
- 分时 / 分钟级因子

## 2. 契约

### 2.1 P0：注册表因子（无新列）

| key | 分组 | 展示名 | 类型 | 表达式（最新 / 回测） | 单位 |
|---|---|---|---|---|---|
| rsi6 / rsi12 / rsi24 | 趋势 | RSI6 / RSI12 / RSI24 | NUMBER | `f.rsi6` 等 | — |
| macdHist | 趋势 | MACD 柱 | NUMBER | `f.macd_hist` | 元 |
| bias20 | 趋势 | 偏离 MA20 | NUMBER | `(close / f.ma20 - 1) × 100`（最新截面取最新收盘，回测取 `f.trade_date` 当日收盘，与 `aboveMa60` 同款子查询） | % |
| bias60 | 趋势 | 偏离 MA60 | NUMBER | 同上（`f.ma60`） | % |
| aboveMa20 | 趋势 | 站上 MA20 | BOOLEAN | `close > f.ma20` | — |
| ma5GtMa10GtMa20 | 趋势 | MA5>MA10>MA20 | BOOLEAN | `f.ma5 > f.ma10 AND f.ma10 > f.ma20` | — |

### 2.2 P1：新列因子（V7 迁移）

列名、口径与缺失语义（全部按标的自身 bar 序列滚动，不对齐日历；缺失一律 NULL，禁止补 0）：

| 列 / key | 分组 | 定义（t 为当日下标，窗口均含当日） | 单位 | 缺失条件 |
|---|---|---|---|---|
| `volume_ratio_5` / volumeRatio5 | 量能 | `vol[t] / mean(vol[t-5..t-1])`（不含当日） | 倍 | t<5 或分母=0 |
| `volume_ratio_20` / volumeRatio20 | 量能 | `vol[t] / mean(vol[t-20..t-1])` | 倍 | t<20 或分母=0 |
| `vol_chg_20` / volChg20 | 量能 | `mean(vol[t-4..t]) / mean(vol[t-19..t]) - 1` | 小数 | t<19 或分母=0 |
| `atr_20` / atr20 | 风险 | `mean(TR[t-19..t]) / close[t]`；`TR = max(high-low, |high-pre_close|, |low-pre_close|)`，`pre_close` 缺失时 `TR = high-low` | 小数 | t<19 或 `close≤0` |
| `amplitude_20` / amplitude20 | 风险 | `mean((high-low)/pre_close)`，仅取窗口内 `pre_close` 非空且 >0 的 bar | 小数 | t<19 或窗口内无有效 bar |
| `downside_vol_20` / downsideVol20 | 风险 | 最近 20 个日收益中**负收益**的样本标准差（分母 n-1） | 小数 | t<20 或负收益个数 <2 |
| `pct_from_52w_low` / pctFrom52wLow | 风险 | `close[t] / min(close[t-249..t]) - 1` | 小数，≥0 | t<249 或 min≤0 |
| `new_high_60` / newHigh60 | 趋势 | `close[t] >= max(close[t-59..t])` → 1，否则 0 | 0/1 | t<59 |
| `new_high_120` / newHigh120 | 趋势 | 同上窗口 120 | 0/1 | t<119 |

注册表表达式：百分比类列 ×100 后进库外展示（与 `return20` 口径一致）；
`newHigh60/120` 为 BOOLEAN，表达式直接用原始列（NULL 时条件不成立，保持缺失语义）。

## 3. 实现要点

1. 指标类（纯函数，`Double[]` 与输入等长，尾部写入）：
   `VolumeStats`（均量 / 量比 / 量能变化）、`Atr`、`Amplitude`、`DownsideVolatility`；
   `PricePosition` 扩展 `pctFromLow`、`newHigh`。
2. `FactorDaily` 增加 9 个可空字段；mapper resultMap / upsert / columns 同步；
   既有调用点显式补 null（不引入兼容构造器，保持数据形状唯一）。
3. `FactorCalculator` 一次遍历组装全部列；契约 javadoc 更新。
4. `FactorComputeService.UPDATE_SLICE_BARS`（510）已覆盖最长回看 250，无需调整。
5. `FactorRegistry`：`GROUP_ORDER` 增加「量能」；17 个新定义均 `available=true`、
   P0 与 P1 均可回测（`backtestExpression` 齐备）。

## 4. 异常、幂等与回滚

- **异常**：单标的计算失败记入 `FACTOR_INIT` 失败列表，不阻断其它标的（既有机制）。
- **幂等**：重复 `--factor.init` 行数不变、值一致；`--factor.update` 只重算尾部窗口。
- **回滚边界**：回填前备份 `data/finance.db`（红线段要求）；验证完成前保留备份。

## 6. 未验证项与剩余风险

- 量比类因子在极低流动性标的（如停牌前后、货币 ETF）可能失真，取决于成交量为 0 的处理（分母 0 → NULL）
- 振幅依赖 `pre_close`，历史极端除权日（数据修复前）可能异常
- 新因子未做因子有效性检验（IC / 分层）；本次仅完成接入与口径验证
- 换手率 / 成交额因子缺数据源，流动性维度仍不完整
